# Paired whole-policy signal experiment

The closed credit/reset trials changed the residual network but did not improve randomized clean missions. The independent-family study also found unstable single-action return rankings (roughly chance agreement between replica halves). This motivates one distinct question: do coherent changes to the network, held fixed throughout deterministic flights, produce action preferences that agree across independent FIT layouts? It does not justify another stochastic gradient run or guarantee parameter search will succeed.

This is a bounded diagnostic of a possible learning method. Candidate commands come from the neural policy at each actual public observation. No command scripts, privileged actor inputs, critic targets, policy gradients or continuation checkpoints are used. Exploration heads are unqualified experimental networks, not successful learned policies.
