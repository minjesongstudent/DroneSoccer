# Older issued commands improve motion prediction

An offline CUDA diagnostic found useful motion information in twelve past issued commands beyond the policy's current three-command history. This is evidence for a controlled history experiment, not evidence of improved flight or simulation acceptance.

The data are complete episodes from the original policy's first 200,000 warmup transitions. No later degraded-policy trajectories, validation layouts or reserved acceptance seeds were used. Every fifth complete episode was held out: 162,290 fitting samples and 36,523 held-out samples after omitting two initial steps per episode. All movements were originally generated by the learned actor.

The target is the next actual displacement, expressed in the body frame before the current action, in millimetres. The public predictor receives the original 85 features and the current issued action. The extended predictor additionally receives nine older commands, for twelve past commands total. All three commands already in the original observation were checked against the recorded action sequence on every sample. No future action or position enters either predictor.

Each predictor is a 128-by-128 tanh neural network trained on CUDA for 1,500 Adam updates, batch size 512, learning rate 0.0003. Feature and target scaling use fitting episodes only. Two initialization/sample seeds were run. A same-width zero-padding control tests whether additional input width alone explains the result.

| Predictor | Held-out per-axis RMSE, seed 1 / seed 2 (mm) | Ring-not-visible RMSE (mm) |
| --- | --- | --- |
| Original public history + current action | 5.647 / 5.608 | 5.826 / 5.772 |
| Same-width zero-padding control | 5.65 / 5.66 | 5.82 / 5.78 |
| Twelve past commands + current action | 4.300 / 4.334 | 4.195 / 4.219 |
| Public + prior displacement from simulator truth, diagnostic only | 3.654 / 3.682 | 3.412 / 3.446 |

The older commands reduce held-out error by approximately 23% overall and 27% when the ring is not visible. Zero padding does not reproduce the gain. A zero-displacement baseline has RMSE 20.098 mm; simply repeating the prior true displacement has RMSE 4.834 mm. The privileged comparison illustrates remaining motion uncertainty; its truth feature must not be inserted into the deployable actor.

Limitations: these are correlated trajectory samples, not independent flight outcomes. No confidence interval or physical accuracy claim is made. The target includes variable control intervals, wall clipping and randomized dynamics. Better one-step prediction does not establish better passage decisions or identify a unique cause of collision. This result supports testing longer command memory, while the earlier longer-camera-history value audit did not show comparable evidence.
